# Design & dev skills

Claude Code skills we used while building/redesigning **nedelya-site**, kept in
the repo for reference and reproducibility.

## What's here

- **`modern-web-design/`** — modern web-design principles, 2024–2025 trends,
  micro-interaction patterns, accessibility and performance checklists. Used for
  the contact-form redesign and general design decisions (layout, depth,
  restraint on motion).
- **`motion-framer/`** — Motion / Framer Motion (`motion/react`) patterns:
  variants, gestures, layout/shared-element animations, spring physics. Used for
  the niche-gallery reveal + shared-layout morph and the contact-form
  micro-interactions.

Each folder mirrors the original plugin layout: the skill body lives in
`skills/<name>/SKILL.md` with `references/`, `scripts/`, `assets/`, plus the
plugin's `agents/` and `commands/`.
